# Демонстрационная версия «Оптика · Заявки»

Эта папка предназначена для отдельной публичной демо-публикации на GitHub Pages. В ней только статический `index.html` с семью вымышленными примерами. Рабочая версия, реальные заявки, файлы CSV и локальное хранилище основного приложения сюда не входят.

Демо автономно: обращения и их изменения хранятся только в локальном хранилище браузера на устройстве посетителя. Другие посетители не увидят изменения. Общей базы данных, входа в аккаунт и передачи заявок на сервер нет. Кнопка «Сбросить демо-примеры» возвращает исходные примеры.

## Опубликовать на GitHub Pages

1. Войдите в GitHub и нажмите **New repository**.
2. Назовите репозиторий, например `optika-demo`; выберите **Public**. Не создавайте репозиторий из рабочей папки приложения.
3. Нажмите **Create repository**, затем **Add file → Upload files**.
4. Откройте на компьютере папку `github-pages-demo` и перетащите в окно GitHub только её файлы: `index.html` и `README.md`. Проверьте, что загружаются именно эти файлы, без CSV, Excel и рабочей версии приложения.
5. Нажмите **Commit changes**.
6. В репозитории откройте **Settings → Pages**.
7. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажмите **Save**.
8. Дождитесь публикации и откройте URL, показанный в разделе Pages. Обычно адрес имеет вид `https://<имя-пользователя>.github.io/optika-demo/`.
9. Проверьте опубликованную страницу: виден баннер «Демо-версия», есть семь примеров, а в репозитории нет рабочих данных.

При обновлении демо загрузите изменённый `index.html` в этот же отдельный репозиторий. Не загружайте туда файлы из корня рабочего проекта.
